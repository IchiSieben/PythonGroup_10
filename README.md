# PythonGroup_10

Personal copy of the class materials from a 2018 introductory Python training
(5 sessions, `clase01`–`clase05`: basics, functions/modules, files & images,
exceptions, and a short Flask + Tesseract OCR intro). This is **not** an
original project of Yoichi's: every commit with actual content
(`Classes 01 and 02`, `Classes 02 and 03`, `Latest classes`, `latest class
material`) was authored by **Moisés Cachay**, the course instructor. Yoichi's
only commits are two merges pulling updates from the training organization's
upstream repo (`Area51TrainingCenter/master`) into his own fork of the
classroom repository — he did not write the exercise code himself. The name
`PythonGroup_10` reflects the student group number assigned in that cohort,
not a project Yoichi initiated or a multi-student group collaboration.

### Running it

Unmaintained since 2018 and not verified to run today: `requirements.txt`
pins Pillow 5.1.0 and other packages from that era, `clase05` depends on a
bundled Windows-only `tesseract.exe` and `lept173.dll`, and no environment
setup was tested for this note. Treat the scripts as read-only reference
material, not as a runnable app.

No LICENSE file is added. This repository is training material authored by

to keeping a personal fork in sync via the two merge commits noted above.
